# Checklist d'intégration Cdiscount (Awin)

- [ ] Inscription éditeur effectuée et coûts éventuels confirmés à 0 € avant validation.
- [ ] Site `https://prixbasmalin.fr` accepté par Awin.
- [ ] Programme Cdiscount accessible et accepté dans le compte.
- [ ] Conditions vérifiées : affichage comparatif, prix, livraison, images, cache, durée de conservation, attribution.
- [ ] URL officielle de flux produit obtenue dans le tableau de bord.
- [ ] Format et fréquence du flux connus ; procédure de mise à jour testée.
- [ ] Gabarit officiel d'URL de suivi confirmé.
- [ ] Identifiants secrets stockés dans GitHub Actions Secrets s'ils sont nécessaires ; aucune clé dans les fichiers publics.
- [ ] Au moins deux offres autorisées pour un même identifiant produit testées, sans variantes confondues.
- [ ] Prix total calculé uniquement lorsque prix produit et frais obligatoires sont disponibles.
- [ ] Données expirées ou non disponibles exclues ou clairement signalées.
- [ ] Revue de sécurité et d'usage terminée avant activation.
