# Clone Studio

Outil web : photos d'un commerçant → vidéos courtes pour TikTok et Instagram, via l'API Agnès AI (agnes-video-v2.0).

Basé sur « MoneyPrinterTurbo · Agnes », de Laurent Vo Anh (https://github.com/laurentvoanhofficiel-jpg/redesigned-potato), que l'auteur partage librement pour que les développeurs le modifient.

La clé API est saisie par l'utilisateur et reste dans son navigateur (localStorage). Elle n'est jamais envoyée ailleurs qu'à l'API Agnès.
